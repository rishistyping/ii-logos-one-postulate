## Short Citation Note

If you mention Aristotle in a paper, PR description, or project note, cite the
current public report:

- `Aristotle: IMO-level Automated Theorem Proving`

- arXiv: `2510.01346`
- DOI: `10.48550/arXiv.2510.01346`

## Suggested Repo Usage

- In PRs: mention Aristotle if it was used as a checker, repair tool, or counterexample searcher.
- In project notes: cite it when the tool materially influenced a proof repair or review.
- In papers: cite the report if Aristotle was used to formalize, validate, or debug Lean outputs.
